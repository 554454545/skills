# 结账：注册人信息与付款

## 注册人信息（ICANN 要求，全部必填）

| 字段 | 填法 |
| --- | --- |
| 姓名 | 拼音或英文，例如 `San Li` |
| 邮箱 | 必须能收信，之后会收到 ICANN 验证邮件，要点开验证 |
| 电话 | `+国家码.号码` 格式，中国手机写成 `+86.13800000000` |
| 地址 | 拼音或英文，这一栏必须包含字母，纯数字会报错 |
| 城市 | 拼音或英文，例如 `Shanghai` |
| 州/省 | 填省份或直辖市，例如 `Shanghai` |
| 邮编 | 当地邮编 |
| 国家 | 注册人所在国家，可以和信用卡国家不同 |

Cloudflare 会在公共 WHOIS 里隐去这些信息，免费，不用另外买隐私保护。

## 付款信息

- 账单地址必须和信用卡在发卡行登记的地址一致。例如用境外发行的卡，就填发卡地的账单地址；注册人信息照样按注册人实际所在地填写。
- 结账页的 Stripe Link“保存信息”是可选的，不想保存就不勾。
- 完整卡号、安全码不要截图外传，需要求助时先打码。

## 常见报错

- 地址提示无效：检查是否全是数字或含中文，改成含字母的拼音或英文。
- 电话格式错误：去掉空格和横线，写成 `+86.` 加手机号。
- 卡被拒：多半是账单地址和发卡行登记的不一致，或卡没开通境外/线上支付。
